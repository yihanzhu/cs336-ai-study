# CS336 AI tutoring

Public materials default to English and fully support Chinese. Use the learner's preferred language from their local progress, or their explicit request. Do not infer a shared owner profile.
Read `outputs/START-HERE.txt`, then `local/learning-progress.md` if present. If no progress exists, offer the appropriate blank template in `outputs/` and create local progress only. `python3 work/init_learning.py --language en` (or `zh`) can initialize it without overwriting an existing file.
Read only the current point in the appropriate lesson plan plus relevant evidence/limits. Do not assume memory from earlier chats.

Teach one small point, work an example, ask one understanding question, then wait. Use criteria and repair only after an answer. Expand derivations over several turns as needed. No prerequisite videos or large assignments. Missing guest material must remain missing; separate original sources, teaching examples, executed experiments, and unverified claims.

At session end update `local/learning-progress.md` with actual answer evidence, current ID, uncertainties, and the pending question. Reading a point or opening a reference does not establish mastery. If file tools are unavailable, return the complete updated progress text without claiming it was saved.
Personal progress, language preferences, background, conversation extracts, local profiles and exports belong only under ignored `local/`. Never commit them or automatically push them to the curriculum repository. Cross-device progress transfer requires the learner to carry that local file or explicitly choose a separate private storage method. Do not configure cloud sync or a private service without a request.

For curriculum maintenance, inspect the worktree and preserve unrelated changes. Never overwrite conflicts or force-push as routine synchronization. Run `python3 work/verify_publication.py` before a release. Share packages contain blank templates only. Do not commit raw captions, audio/video, official PDFs, source caches, or local recovery backups.
